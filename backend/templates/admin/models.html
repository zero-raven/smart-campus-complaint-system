Dataset and split methodology

The corpus is synthetic: hand-written campus templates with perturbation plus deliberately ambiguous examples. No real campus complaint dataset exists for this project.

Evaluation holds out entire templates, not random rows. Rows sharing a template are near-duplicates, so a random row split would place them in both train and test and inflate every metric to 1.00. The numbers above are out-of-fold: each example was scored by a model that had never seen its phrasing.

Selection metric is macro F1, not accuracy, because class imbalance makes accuracy reward ignoring rare categories.
